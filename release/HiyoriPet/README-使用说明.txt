日和桌宠 HiyoriPet 0.1.4
发布日期：2026-09-06

这是内嵌前端与后端的 Windows Tauri 桌面应用，不依赖 Vite、浏览器开发服务器或手动启动 Python。

启动与实例
- 双击 HiyoriPet.exe 启动；重复双击只唤醒已有的日和，不会生成第二只桌宠。
- 系统托盘可选择“显示宠物”“隐藏宠物”或“退出日和桌宠”。
- 聊天气泡中的“隐藏桌宠”可隐藏窗口；再次从托盘显示。

互动
- 左键短按：触发日和的动作、表情和反馈；不会因为点击弹出设置。
- 左键按住并移动：拖动日和到桌面其他位置。
- 双击：跳跃。
- 滚轮：连续整体放大/缩小，人物会保持完整可见并限制在当前显示器工作区内。
- 右键短按：打开/关闭 AI 接入面板；收纳箱打开时右键短按先关闭收纳箱。
- 右键长按（约 0.7 秒）：打开应用收纳箱。
- 应用收纳箱：把桌面快捷方式（.lnk/.url）拖到日和身上，她会“吃掉”它——快捷方式从桌面消失并按分类收进收纳箱；面板内可打开、改分类、导出还原到桌面或删除。
- Esc 或关闭按钮：关闭当前气泡/AI 面板/收纳箱。
- 气泡只会出现在日和头部左侧或右侧（不遮挡人物），约 3 秒后缓慢淡出；输入框可直接对话。

AI 接入
- 未配置 API 时仍可本地陪伴；对话会明确提示当前未接入 API，并可在右键面板添加。
- 支持 OpenAI-compatible（官方与中转/自定义地址）、Anthropic Messages、Google Gemini；不绑定厂家名单。
- “识别模型”读取接口的模型列表；“测试连接”会发起一次测试请求，可能产生费用。
- 可勾选多个已识别模型，选择主模型/协作/裁决角色，启用 fallback 或 parallel 多模型协作。
- API Key 只保存到当前 Windows 用户的 DPAPI 加密配置，不回传、不写入本目录。

本便携目录必须保持以下文件结构：
- HiyoriPet.exe
- WebView2Loader.dll
- backend\pet-backend.exe
